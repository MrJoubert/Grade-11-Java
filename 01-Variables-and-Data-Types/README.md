
# Variables and Data Types

This section explores how Java stores and represents information in a school management system.

The examples use school-related data such as Student names, admission numbers, marks, subject codes, attendance figures and assessment dates.

## Contents

| Folder | Description |
|---|---|
| Choosing-Appropriate-Data-Types | Selecting suitable data types for different values |
| Data-Type-Ranges | Understanding the ranges and limitations of primitive data types |
| Naming-Conventions | Applying meaningful Java naming conventions |
| Understanding-Data-Types | Working with primitive data types and reference types |
| Understanding-Variables | Declaring, initialising and updating variables |
| Variables-and-Constants | Using variables and constants appropriately |
| Dates-and-Times | Working with dates and times in Java |

## Learning objectives

By completing this section, Students should be able to:

- Select appropriate data types for school-related information.
- Declare, initialise and update variables.
- Apply meaningful naming conventions.
- Distinguish between variables and constants.
- Understand the limitations of different primitive data types.
- Work with date and time values where required.

## School management system context

The examples will use fictional Students, teachers, subjects, classes, marks and school activities to demonstrate how Java represents and processes information.
